Pokémon Mercury Redux — Visual Sprite Approval Browser

Open index.html, then choose a group.
Actual Elite Redux sprite images are loaded from the pinned v2.65beta GitHub source.
Each card shows Front / Back / Icon when a source path resolves.
Mercury-only custom concepts without existing art are not faked; they show a no-art message.
Mark APPROVE / DECLINE / MAYBE and add notes. Your choices persist in that browser via localStorage.
Use “Export this group's decisions” to save a CSV you can send back to ChatGPT.
