How this review works (and how to save to GitHub)

Keep and Cut refer to the specific candidate artwork, not the vanilla Pokémon. For two designs with the same identity, choosing one automatically marks the alternate as not selected. Bulk Keep deliberately skips comparison/conflict cases.

Decisions autosave in this browser. Backup / GitHub JSON downloads an auditable file with the dataset version, complete decisions, notes, and original identifiers. Send that exported file in ChatGPT to have it applied to GitHub, or commit it in the Sprites repository under audit/user-decisions/. Use Restore progress to import a previous export. This webpage cannot silently write into your GitHub account.

Previous GBA KEEP/CUT decisions are preserved in historical-decisions.json. Pending repairs and candidates deliberately held out of your review are in repair-queue.json.
