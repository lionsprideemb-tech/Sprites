How this review works (and how to save to GitHub)

Keep and Cut refer to the specific candidate artwork, not the vanilla Pokémon. Technical SHORTLIST suggestions mean a source is well documented, not that its visual quality has been approved. Native DS preference is provisional and can be overridden. For two designs with the same identity, choosing one automatically marks the alternate as not selected. Bulk Keep deliberately skips comparison/conflict cases.

Decisions autosave in this browser. Backup / GitHub JSON downloads an auditable file with the dataset version, complete decisions, notes, and original identifiers. Send that exported file in ChatGPT to have it applied to GitHub, or commit it in the Sprites repository under audit/user-decisions/. Use Restore progress to import a previous export. This webpage cannot silently write into your GitHub account.

The latest uploaded decisions are imported from a versioned GitHub backup. Earlier choices removed from the undecided pool remain included in later exports, so nothing disappears from your records. In Needs my decision mode, already-chosen siblings stay visible beside the undecided ones.

If you previously made decisions in other Mercury Pages review screens on this same browser, Recover older page choices finds relevant local decision records and includes them in the JSON export without rewriting current choices.
