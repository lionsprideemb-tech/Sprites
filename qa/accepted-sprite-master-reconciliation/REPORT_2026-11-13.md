# Pokémon Mercury Redux — Accepted Sprite Master Reconciliation
**Audit date:** November 13, 2026  |  **Scope:** read-only GitHub audit and isolated QA documentation; not a ROM integration pass.

## Verified result
- **711 distinct source-anchored accepted artwork designs** under explicit identity + exact front-pixel hash, Git blob or path fallback, after later explicit vote precedence and retired-family quarantine.
- **43 additional accepted decision records** lack a verified exact original front-asset path. These must NOT be counted as distinct artwork until sourced/deduplicated. Examples: pikachu-mega, wigglytuff-mega-y, mega-rhyperior, mega-tangrowth, kingdra-mega-x, mega-electivire, mega-magmortar, lapras-mega-y.
- **711 / 711** anchored accepted entries have linked source front/back files in exact Git trees; **462** have all four source views (normal front/back, shiny front/back), leaving **249** without fully verified four-view linkage.
- **382 generated icon candidates** have existing files in paired converted directories, but **zero production approved icon bindings, palette-bank routes, archive indices or runtime tests** were established.
- **58** native 4bpp raw views = **10 normal pairs / 8 four-view sets** as reproduced from exact-source approval rules and the passed November 9 GitHub action. They are NOT production NCGR/NCLR/NARC/ROM assets.
