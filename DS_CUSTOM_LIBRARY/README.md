# Mercury Redux — DS Custom Sprite Library

This folder is the intake library for custom Pokémon sprites drawn for **Nintendo DS / Gen 4 / Gen 5-style presentation**.

## Rules
- Prefer sprites created for DS presentation over GBA conversions.
- Reject simple recolors unless the design materially changes.
- Preserve creator attribution and source/reuse notes.
- Track front, back, icon, shiny and overworld assets separately.
- Nothing here is automatically approved for the final Mercury roster.
