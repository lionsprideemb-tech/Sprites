# DS-Style 64x64 Pokemon Sprite Resource

A collection of DS-style 64x64 battle sprites and 32x32 icon sprites for all Pokemon and forms.

## Directory Structure

- `sprites-raw/` — Unprocessed sprite sheets, organized into:
  - `BattleSpritesResource/` — 256x64 or 256x128 battle sprite sheets (front, front-shiny, back, back-shiny; 256x128 sheets include male + female rows)
  - `IconSpritesResource/` — Icon sprites in various source formats (32x64, 64x32, 32x32, 31x64)
- `sprites-processed/` — Output from `scripts/process_sprites.py`, split into individual transparent PNGs:
  - `front/`, `front-shiny/`, `back/`, `back-shiny/` — 64x64 battle sprites
  - `front-female/`, `front-shiny-female/`, `back-female/`, `back-shiny-female/` — Female variants (only present for species with gender differences)
  - `icon/` — 32x32 icon sprites (first animation frame)
  - `icon-frame2/` — 32x32 icon sprites (second animation frame, synthesized for single-frame sources)
- `scripts/` — Processing scripts and data
  - `data/` — Downloaded PokeAPI CSVs and generated `pokemon_list.json`

## Setup

```bash
python scripts/setup.py
```

Downloads the needed PokeAPI CSV files and generates `scripts/data/pokemon_list.json` (master list of all Pokemon species and forms).

## Scripts

### `scripts/process_sprites.py`

Processes all raw sprite sheets into individual transparent PNGs:

- **Battle sprites**: Chops each sheet into 64x64 frames. Detects and removes the background color per-frame. Skips empty (single-color) frames. 256x128 sheets are treated as male (top row) + female (bottom row).
- **Icon sprites**: Extracts animation frames based on source dimensions:
  - 32x64 / 64x32 / 31x64 — Two real animation frames (true animation)
  - 32x32 — Single frame; frame2 is synthesized by shifting up 1px

Writes `processed_sprites.csv` tracking every output. Columns include:
- `species_id`, `name`, `generation`, `identifier`, `form`, `is_mega`, `is_battle_only`, `mega_dimension_dlc` — Pokemon metadata
- `front`, `front-shiny`, `back`, `back-shiny`, `front-female`, `front-shiny-female`, `back-female`, `back-shiny-female` — Whether each battle sprite variant was produced
- `icon`, `icon-frame2` — Whether icon frames were produced
- `icon_true_animation` — `True` if the source had distinct animation frames, `False` if frame2 was synthesized or absent

## Data Files

- `scripts/data/pokemon_list.json` — Master list of all Pokemon species and forms (generated by `scripts/setup.py`)
- `sprites-processed/processed_sprites.csv` — Processed sprite output tracking (output of `scripts/process_sprites.py`)
- `MISSING_SPRITES.md` — Known missing sprites with no available source
